# 港口生产数字化大屏

基于 Three.js 的港口生产监控大屏，中央为三维港口场景（DOF 景深 + 辉光），左右两侧为生产统计面板，深色科技风，适配 1920×1080 及各类大屏分辨率。

## 运行

ES Module 不能直接用 `file://` 打开（浏览器 CORS 限制），用任意静态服务启动即可：

```bash
npx http-server -p 8080 -c-1 .
# 或
python3 -m http.server 8080
```

然后浏览器访问 `http://localhost:8080`。

> Three.js 已完整本地化到 `vendor/three/`，**无需外网**。

## 自适应布局

页面按 1920×1080 设计稿布局，外层 `#stage` 通过 `transform: scale()` 等比缩放并按窗口居中：

- 任意分辨率（1920×1080、2560×1440、3840×2160、带鱼屏、笔记本小窗）均完整显示，不出现滚动条、不裁切、不变形；
- 窗口尺寸变化时重新计算缩放比，同时重设渲染器尺寸与图表画布（含 DPR），文字与线条不会模糊；
- 面板内部使用 flex 比例分配高度，图表根据容器实际尺寸重绘。

## 后期处理

- `BokehPass` 景深：`focus` 每帧根据相机到主体的距离动态更新（避免硬编码焦距导致全屏虚化），`aperture 0.0005` / `maxblur 0.005`，突出中央港口主体；
- `UnrealBloomPass` 轻度辉光（strength 0.32），强化深色科技风；
- `OutputPass` 保证色彩空间正确。

## 统计面板

- 左侧：今日吞吐量 / 作业效率 KPI（数字滚动 + 环比）、近 12 小时吞吐趋势（时间轴 + 最新值）、各泊位作业效率柱状图、船舶在港动态（泊位 + 作业进度）；
- 右侧：船舶在港 / 堆场利用率 KPI、堆场分区利用率柱状图（高负载变色）、货物类型占比环形图（含图例与百分比）、告警事件列表；
- 中央场景浮层：堆场利用率、岸桥作业台数、泊位占用率。

数据为模拟实时数据（`js/data.js`）：每 3 秒波动 KPI，每 9 秒刷新图表，每 18 秒轮换船舶作业进度与告警；时间轴与告警时间均取真实时钟。

```

css/style.css           深色科技风样式与自适应缩放
js/main.js              舞台缩放、场景/相机/渲染器、DOF 对焦、渲染循环、FPS
js/scene.js             港口模型构建与每帧动画
js/postprocessing.js    DOF + Bloom 后期处理链
js/panels.js            数字滚动、Canvas 图表、列表渲染
js/data.js              模拟实时数据源与订阅分发
vendor/three/           本地化 three.js r160（MIT，见 THIRD_PARTY_NOTICES.md）
```
